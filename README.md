## 三条授权线怎么分，免费版够不够用

Navicat 的产品页里，Data Modeler Lite 是单独列出来的免费版本，和付费版并列。这意味着厂商自己也承认有一批用户不需要付费功能。

免费版能覆盖的场景很有限。你的需求如果只是给一个已经有表结构的库画张图、跟同事对一下字段关系，Lite 够用。但只要涉及逆向工程批量导入、从模型直接生成建表语句、把模型导出成文档交付，就得往上走。

付费版的功能范围是这样的：支持概念模型、逻辑模型、物理模型三层设计，能从现有数据库反向生成模型，也能从模型正向生成 SQL/DDL 脚本；可以从 ODBC 数据源导入模型；表和图的关系用 Crow's Foot、IDEF1x、UML 三种标准记法表达；数据库这边覆盖 MySQL 和 PostgreSQL 这类开源库，也支持 SQL Server、Oracle 这类商业库。这些是这个工具的核心价值，也是它跟“随手画个流程图”的区别。

非商业版和企业版的功能差异不在功能表上，在授权条款上。买非商业授权之前，需要到 Navicat 官网的对应页面确认自己符不符合条件。公司主体、有营收的项目、给客户交付的活，都不属于非商业用途。这一条是真实的合规风险，不是走个形式。用非商业授权干商业项目，被查出来要补授权。

## 常见问题

**PCALL 能用在 Data Modeler 上吗？**

可以。这个码的适用范围是 Navicat 全系列，Data Modeler 属于周边工具，在覆盖范围内。折扣是 9.5 折，无门槛。

**免费版和付费版差在哪？**

免费版是 Data Modeler Lite，功能做了精简，适合简单的 ER 图。付费版支持三层模型设计、正向和逆向工程、从 ODBC 数据源导入、生成 SQL/DDL 脚本，以及三种标准建模记法。要做实际交付的模型，基本都要付费版。

**买永久还是买订阅？**

看你用多久。永久授权一次买断，用超过一年就比订阅划算，而且不用担心第二年调价。项目制、短期用几个月就结束的，订阅更灵活。

**非商业版公司能用吗？**

不能。非商业授权有明确的资格要求，购买前需要在 Navicat 官网确认条件。公司主体、有营收的项目、给客户做的交付，都属于商业用途，要用 Enterprise 授权。

**9.5 折是不是最低价？**

这是目前公开可查的唯一一个通用折扣。Navicat 官网自己的促销活动会不定期出现，但之前那轮 8 折已经在 2026 年 8 月 6 日结束。想要更低的价格，一般得等官方活动或走批量授权。
